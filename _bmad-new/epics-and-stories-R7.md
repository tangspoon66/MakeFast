## 1. 切分原则

- PED：目录零引导 → 进课 WHY 引导 → 硬件成功 → 课后测验。  
- 故事可测、可演示；验收映射 F-* / US-*。  
- 不出现淡出、过程 quiz、Wiring Graph SoT。  
- P0 = 第一课快乐路径；P1 = 续导/管理。

## 3. Stories（P0）

### E1 课程目录与选课

#### ST-E1-01 目录卡片六要素
**作为**学习者，**我想**在目录看到封面/标题/星级/入门标签/板型标签/分类，**以便**判断学哪门。  
**验收：** F-CAT-01；缺图有占位；亮色儿童视觉（可先组件后视觉抛光）。  
**替代：** —  

#### ST-E1-02 默认入门筛选与第一课置顶
**验收：** F-CAT-02/04；默认「入门教程」；第一课「开始这里」。  

#### ST-E1-03 开始课程进入工作台
**验收：** F-CAT-03；CTA「开始课程」创建 session 且目录无强制 Agent 蒙层；进工作台前 agentState=IDLE。  

#### ST-E1-04 目录 Agent 静默
**验收：** M7；目录无 guide_step；猫可 Idle。

### E2 课内 Agent 引导

#### ST-E2-01 进课启动 GUIDING
**验收：** F-AGT-01；PATCH surface=workbench 后进入 GUIDING；回目录→IDLE。  

#### ST-E2-02 步骤结构 do/why/success
**验收：** F-AGT-02；UI 为 GuideStepCard；过程无题面。  

#### ST-E2-03 失败解释不锁 quiz
**验收：** F-AGT-04；编译/烧录失败可解释+重试，无答题门闩。  

#### ST-E2-04 主线后收束导向测验
**验收：** F-AGT-05；phenomenon success → WRAP_UP → quiz 可开。

### E3 连线图与板级校验（替换 ST-403）

#### ST-E3-01 连线图面板文案与渲染
**作为**学习者，**我想**看到标题为「连线图」的第一课接线说明。  
**验收：** F-WIR-01；无对外 Wiring Graph；展示 XIAO+DHT22+有源蜂鸣器。  
**替换：** ST-403  

#### ST-E3-02 board.json 加载与真源
**验收：** F-WIR-02；GET board；能力来自 board.json。  

#### ST-E3-03 ConnectionGraph 校验
**验收：** validate-graph API；非法连接 childMessage 可读；课包图通过校验。  

#### ST-E3-04 GPL 边界自检清单
**验收：** F-WIR-04；实现清单无 aily 壳/资源拷贝项（工程任务，可勾选文档）。
