---

## 1. 体验目标

学习者感到：**先看清课 → 安心选课 → 进课才有人带 → 每步懂 WHY → 做出真实现象 → 再测验巩固**。全程不被突然提问打断，也不在目录被 Agent 抢走注意力。

---

## 2. 假设（Assumptions）

| ID | 假设 |
|---|---|
| AX-01 | 第一课默认 DHT22 + 有源蜂鸣器（同 PRD A-01） |
| AX-02 | 单次会话以「一门课」为边界；目录与课内是两种 Agent 姿态 |
| AX-03 | 儿童注意时长有限：课内单步引导文案 ≤ 2 短句 + 1 个 WHY |
| AX-04 | 失败不可耻：编译/烧录失败用鼓励语气 + 可执行下一步，不责备 |
| AX-05 | 奖励以「完成与理解」为主，不以「减少帮助」为荣 |

---

## 3. 端到端体验节奏（PED 新版）

旧 PED（过程练习 / 穿插测评 / 协助淡出）**整段作废**。

### 新 PED

```text
浏览（零引导）→ 选课 → 课内逐步引导+WHY（零 quiz）
  → 硬件成功 → 收束 → 课后测验 →（可选）庆祝/回目录
```

| 阶段 | 用户感受 | Agent 姿态 | 时长感（设计目标） |
|---|---|---|---|
| 目录浏览 | 像逛书架，不被催 | IDLE | 随意 |
| 点开始 | 明确「我选了这门」 | 仍 IDLE 直至工作台就绪 | 瞬间 |
| 课内引导 | 有人陪、讲清楚为什么 | GUIDING | 第一课主线 25–45 min（Assumption） |
| 工具链 | 顶栏步骤像闯关但无考题 | GUIDING | 含在主线内 |
| 现象成功 | 「真的做出来了」 | WRAP_UP | 短 |
| 课后测验 | 巩固，不是刁难 | QUIET_HELP | 3–8 min |
| 回目录 | 可再选别的课 | IDLE | — |

---

## 4. 分表面体验规格

### 4.1 课程目录

**要：**

- 卡片一眼看出：封面叙事、标题、难度星、入门标签、ESP32 等标签、分类。
- 默认「入门教程」；第一课「开始这里」。
- 主色亮、圆角大、字号儿童友好（具体交给 R4，本处定意图）。

**不要：**

- 自动弹出 Agent 开讲、语音抢麦、强制蒙层。
- 未进课就要求接线/测验。

**微文案默认：** 空态可用一句非打断提示「点卡片开始一门课」（可关闭，不循环追问）。

### 4.2 进入课程 / 工作台

- 进入动画短；Agent 第一句：**本课要做什么 + 今天为什么学这个**（WHY 总览），然后进入步骤 1。
- 顶栏始终可见：板型 → 连接 → 编译 → 烧录；当前步高亮。
- 底栏串口默认折叠或矮轨，需要时展开（Assumption：默认可见一行最新输出）。

### 4.3 课内逐步引导

每步固定结构（对学习者可见）：

1. **现在做：** 一句话动作  
2. **为什么：** 一句话 WHY  
3. **成功时：** 会看到/听到什么  

允许：高亮 UI、连线图焦点、重试、鼓励。  
禁止：选择题、对错门闩、「答对再继续」。

失败时：

- 说明可能原因（儿童句）；
- 给一个下一步（检查线 / 再编译）；
- 不扣分、不降「自主等级」。

### 4.4 连线图

- 文案只说「连线图」。
- 图与 DHT22、有源蜂鸣器一致；颜色对比足够。
- 与板型步骤联动：未确认板型时提示先选板（引导，非 quiz）。

### 4.5 连接 / 编译 / 烧录 / 串口

- 状态用交通灯语义（色 + 短词），避免堆栈原文砸脸；详情可展开。
- 编译失败：Agent 用 WHY 解释「编译是把想法变成板子能懂的话」+ 具体建议。
- 串口出现温湿度：庆祝瞬间（短），然后导向「主线完成」。

### 4.6 课后测验

- 仅主线成功后出现入口。
- 语气：巩固小练习，不是考试恐吓。
- 3 选择 + 1 操作复核；错了可重试，展示简短解析（课后允许「教」，仍不算过程门闩）。
- 通过后：明确庆祝 + 回目录 CTA。

### 4.7 Agent / 赛博猫

- 位置右下；目录态猫可 Idle 动画但不说话催促。
- 课内才进入引导台词态。

## 5. 情绪与语气

| 情境 | 语气 |
|---|---|
| 目录 | 轻松、好奇 |
| 引导 | 清晰、耐心、每步有 WHY |
| 失败 | 没事、我们再试 |
| 成功 | 短促真诚庆祝 |
| 测验 | 轻松巩固 |

禁用：嘲讽、焦急倒计时、淡出羞耻（「你该独立了」）。

---

## 6. 无障碍（产品层最低）

- 关键对比满足亮色方案下的可读性（R4 详化）。
- 关键控件不只靠颜色。
- 测验与引导文案避免仅依赖听觉（蜂鸣操作复核可辅以串口/视觉确认）。

---

## 7. 作废的旧体验结论

| 旧 | 新 |
|---|---|
| assisted→autonomous 淡出节奏 | 课内持续引导直至主线完成 |
| 过程穿插 quiz | 仅课后测验 |
| 目录即开场引导 | 目录 IDLE |
| Wiring Graph 体验叫法 | 连线图 |
| 以「少求助」为荣耀指标 | 以完成与理解、低挫败为荣耀 |
