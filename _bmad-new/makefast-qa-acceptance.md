## 5. M7 专项（目录强引导 = 发布阻塞）

### 5.1 定义（严格按 R8 §4.2）

目录（及未进课详情）不得出现：

1. 强制引导蒙层；  
2. 自动开讲；  
3. 下发 `guide_step`。

对照 R7 **ST-E1-04**：目录无 `guide_step`；猫可 Idle。  
对照 Experience R3：目录像逛书架；点开始前仍 IDLE 直至工作台就绪；目录态猫可 Idle 但不说话催促。  
对照 API R6：目录态不下发 `guide_step`；创建 session 时 `agentState: IDLE`。

**结果：** 下列任一项失败 ⇒ **禁止发版 / 禁止标 M-P0a 完成**。

### 5.2 检查场景（可执行）

| 场景 ID | 场景 | 步骤 | 期望 | 方法 |
|---|---|---|---|---|
| M7-S1 | 自动化：catalog 零 guide_step | 在 catalog（及未进课 detail）surface 下采集 Agent 事件 | `guide_step` 事件数 = **0** | 自动化 / 日志断言（R8 §4.2-1） |
| M7-S2 | 手工：冷启动只逛目录 2 分钟 | 冷启动 → 只浏览目录 2 分钟 → 不点开始课程；可滑列表、切筛选 | 无强引导蒙层；无自动开讲；无逐步引导 | 手工（R8 §4.2-2）；与 QA-M7-01 同源加深 |
| M7-S3 | 配置审计 | 检查默认配置：无「全局 onboarding 强制」对目录生效且默认开 | 默认不对目录强制开讲 | 配置审计（R8 §4.2-3） |
| M7-S4 | 开始课程前 IDLE | 点「开始课程」创建 session，在工作台就绪前读 agentState | `agentState=IDLE`；目录无强制 Agent 蒙层 | 手工 + session（ST-E1-03） |
| M7-S5 | 猫 Idle | 目录观察赛博猫 | 可 Idle 动画；不说话催促（Rive 资源缺则静态占位，G-05，仍不得催促开讲） | 手工 |
| M7-S6 | 详情仍不引导 | 若存在课详情（未进工作台） | 仍不启动逐步引导；CTA「开始课程」（PRD IA） | 手工 |
| M7-S7 | 回目录再静默 | 课内 GUIDING 后回目录 | IDLE；引导停；无 guide_step | QA-AGT-02 |

允许：非打断、可关闭的空态一句「点卡片开始一门课」（Experience R3 §4.1）。  
禁止：循环追问、强制蒙层、目录自动开讲、catalog 下 `guide_step`。

### 5.3 M7 与 M-P0a

- M-P0a = 目录 + 进课 Agent 边界可演示（PRD / R7）。  
- **M7 未通过 ⇒ 不得标 M-P0a 完成，亦不得发版。**
