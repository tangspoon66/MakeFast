### 1.5 阴影（柔阴影，建议值）

|---|---|---|

## 2. 全局控件四态约定

所有可交互控件至少定义四态；步进器另有业务态（见 §6）。

| 状态 | 视觉意图 | 通用规则 |
|---|---|---|
| **默认** | 清晰可点；主色或白底+主色描边 | 对比度足够；文案完整 |
| **Hover** | 轻微抬升/加深；光标 pointer | 阴影升一级；不改变布局尺寸 |
| **禁用** | 降对比；不可点 | 透明度约 0.45–0.5 或灰字；无 hover 抬升；`cursor: not-allowed` |
| **错误** | 错误色描边/图标 + 短句 | 短句在控件旁或下方；详情折叠；**配图标/短词，不只靠红** |

焦点：所有可聚焦控件显示 Focus Ring（Primary 外环 2–3px + 2px 白间隔，建议值）；键盘 Tab 顺序：顶栏 → 主区 → 连线图 → 串口 → Agent。

## 3. S1 课程目录 · 高保真说明

### 3.1 布局与层级

```
S0 壳：顶栏品牌「MakeFast」 | 右上头像/设置（P1，可占位）
主内容：筛选条 → 课程卡片栅格 →（可选空态）
右下：赛博猫 Idle（低幅度）；引导气泡默认关闭
```

- **层级**：品牌顶栏（固定）→ 筛选（粘性可选）→ 栅格内容 → Agent 猫（最上层但不挡主 CTA）。
- **桌面优先**：内容区建议 ≥1280 宽；栅格 3 列起（窄桌面 2 列，平板缩放）。
- **背景**：整页 Surface `#C0E2F9`；卡片白底叠柔阴影。

### 3.2 筛选条 C-CAT-FILTER

| 项 | 规格 |
|---|---|
| 默认选中 | 「入门教程」 |
| 其他项 | 「全部」、芯片/生态筛选（如 ESP32） |
| 形态 | 胶囊 Chip；选中：Primary 底 + 白字；未选：白/浅底 + Text/Secondary |
| 间距 | Chip 间距建议 8–12px；条与栅格间距 16–20px |

**四态**

| 状态 | 表现 |
|---|---|
| 默认 | 未选 Chip 浅底；选中 Primary |
| Hover | 未选 Chip 边框 Primary 浅描边；选中略加深 |
| 禁用 | 某筛选不可用时灰显（少见） |
| 错误 | 一般无错误；若筛选结果异常走空态而非红框 |

### 3.3 课程卡片栅格 C-CAT-GRID

- 列：建议 `minmax(260px, 1fr)` 自适应，gap **建议 16–20px**。
- 卡片最小可点高度：封面 + 信息区 + CTA，整体约 320–380px（建议）。
- 第一课（主线入口）显示角标「开始这里」（Accent），与主 CTA「开始课程」并存、不打架。

### 3.4 空态 C-CAT-EMPTY

- 插画或简洁图标 + 一句非打断文案（例：「这会儿没有匹配的课，换个筛选试试」）。
- **无**强制蒙层、**无**自动 Agent 开讲。
- 可选提供「清除筛选」次要按钮。

### 3.5 赛博猫（目录）· 目录不抢引导

| 项 | 规则 |
|---|---|
| 位置 | 右下 AgentDock 区域；猫可见 |
| Rive | **Idle**；低幅度循环，避免抢注意力 |
| 引导气泡 | **关闭** |
| Tip | 最多 1 句可关闭的非打断 Tip；用户可关；**禁止**强制蒙层 / 自动开讲 |
| S1a | 同样 Idle + 引导关闭 |

### 3.6 S1 关键文案键

| 键 | 用户可见文案 | 禁止 |
|---|---|---|
| `cta.start` | 开始课程 | 开始挑战测验（目录） |
| `badge.startHere` | 开始这里 | — |
| `filter.beginner` | 入门教程 | — |
| `filter.all` | 全部 | — |

### 3.7 S1a 课程详情（简要）

- 侧抽屉或薄层：大封面、标题/星/标签、2–4 句说明、材料清单、主 CTA「开始课程」。
- 返回「← 返回目录」；无 Agent 引导气泡。

### 3.8 S1 交互控件四态汇总（目录页）

| 控件 | 默认 | Hover | 禁用 | 错误 |
|---|---|---|---|---|
| 筛选 Chip | 见上 | 描边/加深 | 灰 | 走空态 |
| 课程卡片 | 白底 Shadow/Card | Shadow/Hover + 轻微上移 2px | 整卡不可点灰显（稀有） | 加载失败：封面占位 +「加载失败」短句 |
| CTA「开始课程」 | Primary 实心、圆角 12–16 | 略深 Primary + Shadow/Hover | 灰底灰字 | 进课失败：按钮旁错误短句+建议 |
| Tip 关闭钮 | Ghost 小图标 | 底浅灰 | — | — |
| 头像/设置 P1 | 圆形占位 | 浅环 | — | — |

## 4. CourseCard（C-CAT-CARD）视觉规格表

### 4.1 六要素 + CTA

| # | 要素 | 视觉规格 |
|---|---|---|
| 1 | 封面 | 顶区 16:10 或 4:3 插画感图；圆角随卡片上缘 **18–20px**；加载失败用浅占位 |
| 2 | 标题 | Body/Strong 16px，最多 2 行截断；色 Text/Primary |
| 3 | 星级难度 | C-STAR 只读；实星 Accent 或 Primary 描边星；空星浅灰；旁可跟短词 |
| 4 | 入门标签 | Chip「入门」；Radius/XS；浅 Primary 底或白底+Primary 字 |
| 5 | 板型/生态标签 | 如「ESP32」「Arduino」；同一 Chip 族，可多枚横排 gap 6–8px |
| 6 | 分类 | 如「入门教程」；Caption；Text/Secondary |
| + | CTA | 「开始课程」全文；主按钮 Primary；宽近满卡片内边距；高 **建议 44px**；圆角 **12–16px** |

### 4.2 结构与间距意图

```
┌─────────────────────────────┐  ← Radius/LG 18–20px；Shadow/Card
│ [封面]          ┌开始这里┐  │  ← 角标叠封面右上或左上；Accent 底+深字
│                 └────────┘  │
│ 标题（1–2 行）               │  ← padding 12–16px
│ ★★☆  ·  [入门] [ESP32]      │
│ 分类：入门教程               │
│ ┌─────────────────────────┐ │
│ │      开始课程            │ │  ← Primary CTA
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

### 4.3 角标「开始这里」

| 项 | 规格 |
|---|---|
| 文案 | 开始这里 |
| 色 | Accent `#F4C65C` 底；字 `#1A2B3C` 或略深 |
| 字号 | Micro 12px / 500 |
| 圆角 | Radius/XS 8px |
| 原则 | **点缀引导入口，不替代、不抢主 CTA「开始课程」** |

### 4.4 卡片四态

| 状态 | 表现 |
|---|---|
| 默认 | 白底、Shadow/Card、CTA Primary |
| Hover | Shadow/Hover；整卡可微抬升；CTA 同步 hover |
| 禁用 | 灰显；CTA 禁用；无抬升（如课未解锁） |
| 错误 | 封面错误占位；底部或 CTA 旁 Error 短句（例：「打不开这门课，稍后再试」） |

### 4.5 点击热区

- 点 CTA 或卡片主体 → 进入 S2。
- 可选：点封面非 CTA 区 → S1a 详情（仍无 Agent 强引导）。

## 5. S2 课程工作台 · 高保真说明

### 5.1 壳层布局（冻结）

```
顶栏：← 目录 | 课名 | C-TOP-STEPPER（板型→连接→编译→烧录）
主区：左 C-EDITOR（积木/代码） | 右 C-WIRING「连线图」面板
底栏：C-SERIAL 串口 Dock（可折叠，最新行预览）
右下：C-AGENT-DOCK + 赛博猫 Guiding + C-AGENT-STEP 引导卡（默认开）
```

- 顶栏高度建议 56–64px；主区与底栏分割清晰。
- 右栏连线图建议宽 320–400px（桌面）；可拖拽宽度为 P1。
- AgentDock 浮于右下，不永久遮挡编辑器主操作；可手动收起引导卡正文、保留猫。

### 5.2 顶栏

| 元素 | 规格 |
|---|---|
| 返回 | 「← 目录」Ghost/文字按钮；Hover 浅底 |
| 课名 | H1/H2；单行截断 |
| 步进器 | 见 §6；水平居中或顶栏右侧主视觉区 |

**四态（返回钮）**：默认文字 Secondary；Hover 底浅；禁用（极少）；错误无。

### 5.3 连线图面板 C-WIRING（S2a）

| 项 | 硬约束 / 规格 |
|---|---|
| **面板标题** | 固定用户可见文案 **「连线图」** |
| **禁止** | 任何用户可见位置出现「Wiring Graph」 |
| 文案键 | `wiring.title` = 连线图 |
| 内容 | 课包图：元件节点 + 连线；图例/引脚提示用儿童短句 |
| 焦点联动 | 引导步进时可高亮对应元件（描边 Primary 或 Accent 脉冲，建议） |
| 容器 | Radius/LG；Surface/Panel 内衬；标题栏 H2 |

**面板控件四态**

| 控件 | 默认 | Hover | 禁用 | 错误 |
|---|---|---|---|---|
| 面板本身 | 标题「连线图」+ 图 | 元件 hover 显示名称 tip | 图未加载时骨架屏 | 加载失败：短句+「重试」 |
| 图例开关（若有） | Ghost | 浅底 | 灰 | — |

### 5.4 串口底栏 C-SERIAL（S2b）

| 项 | 规格 |
|---|---|
| 折叠 | 标题「串口」+ ▾/▸；折叠时仍显示**最新一行**预览 |
| 操作 | 「清空」等次要按钮 |
| 成功确认 | 与视觉通道并存（蜂鸣成功等可在串口看到对应输出） |

**四态**：默认展开或记用户偏好；Hover 行高亮；禁用清空（无输出时）；错误行可用 Error 色前缀图标+短词。

### 5.5 主区编辑器 C-EDITOR

- 对界实现；本规格只要求：白/浅底、足够边距、不与 Agent 抢主按钮热区。
- 四态由编辑器自身定义；工具链错误时顶栏步进 error，编辑器可旁注短句。

### 5.6 Agent（工作台）

| 项 | 规则 |
|---|---|
| 表面 | S2 **GUIDING** |
| 猫 | Rive **Guiding** 表情 |
| 引导卡 | **C-AGENT-STEP 默认开启** |
| 位置 | 右下 Dock |

详规见 §7。

### 5.7 S2 文案键

| 键 | 正确 | 禁止 |
|---|---|---|
| `wiring.title` | 连线图 | Wiring Graph |
| `serial.title` | 串口 | — |
| `step.board` / `connect` / `compile` / `flash` | 板型 / 连接 / 编译 / 烧录 | — |

## 6. ToolchainStepper（C-TOP-STEPPER）视觉规格表

### 6.1 步骤顺序（冻结）

**板型 → 连接 → 编译 → 烧录**

形态意图：**胶囊感**整轨（Radius/Pill 浅底）+ 内嵌四步；步与步之间箭头或短线连接。

### 6.2 业务状态 ↔ 交互四态映射

| 业务态 | 含义 | 与默认/hover/禁用/错误的对应 |
|---|---|---|
| **todo** | 未开始 | 视觉近「默认」未激活：浅底、Secondary 字、空心圆点；可 hover 预览；若前置未满足则点击≈禁用反馈（引导短 Tip，非 quiz） |
| **current** | 当前步 | 高亮≈强化默认：Primary 底或 Primary 描边加粗、白/深字、实心进度点；hover 略加深 |
| **done** | 已完成 | Success 勾图标 + 短词「完成」；可点击回看；hover 允许 |
| **error** | 失败 | **错误**态：Error 描边/图标 + 短词（如「失败」）；旁短句+建议；详情折叠 |

另：**禁用**用于整链不可用（如未进课）：全部灰、无 hover。

### 6.3 色 / 字号 / 圆角

| 项 | 规格 |
|---|---|
| 轨底 | Surface 或白；Radius/Pill |
| 步进块 | 圆角 **12px**（建议）；内边距 8×14px（建议） |
| 字号 | Body/Strong 14–16px；短词 Micro 12px |
| 图标 | 每步配图标或序号；**状态不只靠颜色**（勾 / 点 / 感叹号） |
| current | Primary `#74B0E1` |
| done | Success `#3CB87A` |
| error | Error `#E85A5A` |
| todo | `#E8F4FC` 底 + Text/Secondary |

### 6.4 交互

- 可回看 **done** 步。
- 点击未满足前置的 **todo**：弹出非 quiz 引导提示（可与 Agent 卡文案一致方向），不跳转强行执行。
- 焦点环可见。

### 6.5 步进器四态速查

| 交互态 | 表现 |
|---|---|
| 默认 | 按业务态着色 |
| Hover | 可点步抬升/描边；不可点步无抬升 |
| 禁用 | 整轨灰 |
| 错误 | 当前或该步 error 业务态展示 |

## 7. GuideStepCard（C-AGENT-STEP）三栏布局规格

### 7.1 结构

```
┌──────── AgentDock（右下）─────────────────────┐
│  ┌─ GuideStepCard ─────────────────────────┐  │
│  │  [现在做]  │  [为什么]  │  [成功时]     │  │
│  │  短指令    │  一句原因  │  可观察结果   │  │
│  │─────────────────────────────────────────│  │
│  │              [ 下一步 ]                  │  │
│  └─────────────────────────────────────────┘  │
│              （赛博猫 Rive Guiding）            │
└───────────────────────────────────────────────┘
```

三栏：**现在做 / 为什么 / 成功时**，底部主操作 **下一步**。

### 7.2 尺寸意图（建议值）

| 项 | 建议 |
|---|---|
| 卡片总宽 | 340–400px |
| 三栏 | 等分或 1.2 : 1 : 1（「现在做」略宽）；栏间距 8–12px |
| 栏内 padding | 10–12px |
| 卡片圆角 | Radius/XL **24px** 或 Radius/LG **20px** |
| 单栏圆角 | Radius/MD **16px** |
| 猫尺寸 | 约 96–128px 画布；在卡片下方或右下角叠放 |
| Dock 边距 | 距视口右/底 **16–24px**；避开串口折叠条 |

### 7.3 字号与色

| 区域 | 字号 | 色 |
|---|---|---|
| 栏目标题（现在做/为什么/成功时） | Caption 13–14 / 600 | Primary 或 Text/Secondary |
| 栏内正文 | Body 15–16 / 400 | Text/Primary |
| 「下一步」 | Body/Strong 16 | 白字 on Primary |
| 卡片底 | — | 白或极浅 Surface；Shadow/Dock |

「下一步」按钮：圆角 12–16px；高 40–44px。

### 7.4 可见性规则（硬约束）

| 表面 | 猫 | 引导卡 |
|---|---|---|
