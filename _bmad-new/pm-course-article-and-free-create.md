# PM 结论落地：课文章节页 + 自由创作（P0）

## 路径

1. **目录 / Hub 卡片**只留 CTA「开始课程」（不要「开始创作」）。
2. 点进去 → **课文章节页**（像书的一章）：年龄档文案、章节目录、B 站嵌入位、资料区（PDF / STL）。
3. 页内 sticky「**开始创作**」→ 课程工作台（GUIDING）。
4. 章节页 Agent = **IDLE**（M7：非工作台不下发引导）。

## 自由创作

- 已登录：Hub / 顶栏「自由创作」→ 同一工作台壳，`?mode=free`。
- 无强制引导步骤 / 进度闸 / 课后测验；Agent 只做工具助手（问答、编译报错），不自动 GUIDING。
- 未登录点「自由创作」→ 登录页（带回来源）。

## 后台

- 课程包可挂 `resources[]`（pdf / stl）；管理员可上传，学生章节页资料区可读。
