## 1. 目标与非目标

### 1.1 目标

让儿童/青少年学习者能够：

1. 在**课程目录**看清「课做什么」并自主选课；
2. **进入课程后**才获得 Agent 逐步引导（含 WHY），完成 XIAO ESP32-S3 第一课：温湿度感知 + 蜂鸣器反馈；
3. 走通工作台顶栏 **板型 → 连接 → 编译 → 烧录**，用底栏串口验证现象；
4. **主线成功后再**完成课后测验。

### 1.2 非目标（本阶段）

- 目录页 / 未选课状态下的强制引导或开场白式 Agent 打断；
- 过程中提问、quiz、答对才解锁下一步；
- assisted → autonomous 引导淡出作为主进度体系；
- 对外使用「Wiring Graph」命名或将其宣称为连线 SoT；
- 硬抄 aily 受 GPL 约束的壳、主题或源码；
- 重开已定色板与工作台顶栏信息架构；
- 强制绑定某品牌整套 SKU（见 Assumptions）。

## 2. 人物与场景

| 角色 | 核心场景 |
|---|---|
| 访客 | 打开 App → 目录浏览 → 理解第一课 → 决定开始或离开 |
| 学习者 | 选第一课 → 在引导下接线/连接/编译/烧录 → 看串口/听蜂鸣 → 课后测验 |
| 课程管理员 | 维护课程卡片元数据与课包（板型、连线、引导脚本、测验） |
| 平台管理员 | 环境、权限、试点指标 |

**主路径人物：学习者。**

## 3. 假设（Assumptions）

| ID | 假设 | 若否决时的改法 |
|---|---|---|
| A-01 | 第一课温湿度默认 **DHT22**；蜂鸣器默认 **有源蜂鸣器** | 改课程包配置/元数据，不改主流程 |
| A-02 | 硬件形态为「板 + 单温湿度模组 + 蜂鸣器」，**不强制**品牌套件 SKU | 若必须 SKU，仅改采购说明与开箱文案 |
| A-03 | aily **无**现成法务「可对标」批注；实现与 R5 按 **只对标行为与约定、不复制壳** | 法务结论只加减白名单，不改产品对外命名 |
| A-04 | 第一课官方板型为 Seeed **XIAO ESP32-S3** | 换板等于新课，不在本 PRD 并行首发 |
| A-05 | 目录参考截图仅借 **信息结构**，视觉按亮色儿童重做 | — |
| A-06 | 「现象成功」优先自动检测串口温湿度输出；检测不稳时允许一键「我看到了/听到了」 | — |
| A-07 | 课后测验：3 选择题 + 1 操作复核；通过 = 选择 ≥2 正确 **且** 操作复核通过 | 可调题量，不调「课后才测」 |

## 4. 信息架构与主路径

### 4.1 表面

```text
App Shell（亮色儿童）
├── 课程目录 / 总览     Agent 静默
│   └── 课程详情（可选） 仍不启动逐步引导；CTA「开始课程」
├── 课程工作台           进课后 Agent 引导态
│   ├── 顶栏：板型 → 连接 → 编译 → 烧录
│   ├── 主区：程序（积木/代码）+ 连线图
│   ├── 底栏：串口
│   └── Agent（右下）+ 赛博猫 Rive
└── 课后测验             主线完成后解锁
```

### 4.2 快乐路径（SHALL）

系统 SHALL 支持且产品文案引导以下顺序：

1. 打开 App → 课程目录（默认筛「入门教程」，第一课置顶或「开始这里」）；
2. 用户点第一课「开始课程」→ 进入该课工作台；
3. Agent 启动本课逐步引导（每步：目标 + WHY + 成功态）；
4. 确认板型 XIAO ESP32-S3；
5. 按**连线图**完成 DHT22 + 有源蜂鸣器接线；
6. 连接设备 → 编译 → 烧录；
7. 串口见到温湿度输出，蜂鸣器有可感知反馈（或用户确认现象）；
8. 主线完成 → 解锁课后测验 → 用户完成测验。

## 5. 功能需求（SHALL）

### 5.1 课程目录

| ID | 需求 | 验收 |
|---|---|---|
| F-CAT-01 | 系统 SHALL 以卡片展示课程：封面、标题、星级难度、入门类标签、板型/生态标签（如 ESP32、Arduino）、分类（如入门教程） | 卡片六要素可见；缺图有占位 |
| F-CAT-02 | 系统 SHALL 提供分类/筛选；**默认**选中「入门教程」；可切至全部 | 首屏默认入门；切换后列表更新 |
| F-CAT-03 | 系统 SHALL 提供「开始课程」作为进入工作台的主 CTA；目录页 SHALL NOT 出现强制引导蒙层或自动开讲 | 无选课无法进入逐步引导态 |
| F-CAT-04 | 第一课卡片 SHALL 置顶或带「开始这里」标识 | 目录中第一课一眼可辨 |

### 5.2 Agent 与引导

| ID | 需求 | 验收 |
|---|---|---|
| F-AGT-01 | Agent 逐步引导 SHALL **仅**在用户进入某课程工作台后启动 | 目录/详情页无逐步引导脚本执行 |
| F-AGT-02 | 每步引导 SHALL 包含：做什么、**WHY**、成功长什么样；SHALL NOT 在过程中提问或 quiz | 抽检任意课内步骤无题面 |
| F-AGT-03 | 用户返回目录时，该课引导 SHALL 暂停；再次进入同一课 SHOULD 从进度续导（P1 做强） | 暂停可测；续导 P1 |
| F-AGT-04 | 编译/烧录失败时 Agent MAY 解释原因与 WHY；SHALL NOT 以答题解锁重试 | 重试按钮不依赖答对 |
| F-AGT-05 | 主线完成后 Agent SHALL 收束引导并导向课后测验；测验中 MAY 答疑但 SHALL NOT 阻挡已完成主线 | 测验可跳过答疑 |

### 5.3 板型、连线、设备与工具链

| ID | 需求 | 验收 |
|---|---|---|
| F-BRD-01 | 工作台顶栏 SHALL 含板型步骤；第一课板型为 XIAO ESP32-S3 | 板型态可见且正确 |
| F-WIR-01 | 产品对外文案 SHALL 使用「连线图」；SHALL NOT 对外使用「Wiring Graph」 | UI/帮助/课程文案扫描通过 |
| F-WIR-02 | 连线能力与合法性校验的产品真源 SHALL 为板级 `board.json`（对内模型可称 ConnectionGraph）；行为对标 aily 约定 | 文档与验收用例写明真源层级 |
| F-WIR-03 | 第一课连线 SHALL 覆盖 DHT22 与有源蜂鸣器（型号可配置，默认见 A-01） | 连线图与课包一致 |
| F-WIR-04 | 实现 SHALL NOT 复制 aily 的 GPL 壳/主题/源码；仅对标行为与约定（A-03） | R5/实现清单无搬壳项 |
| F-DEV-01 | 顶栏 SHALL 含连接步骤与清晰连接状态 | 未连接/已连接/失败可区分 |
| F-BLD-01 | 顶栏 SHALL 含编译；失败信息对儿童可读（短句+建议） | 故意错误可看到可读提示 |
| F-FLS-01 | 顶栏 SHALL 含烧录；展示进度与结果 | 成功/失败态可测 |
| F-SER-01 | 底栏 SHALL 提供串口面板；第一课烧录成功后可见温湿度相关输出 | 有输出或明确「等待数据」 |
| F-HW-01 | 系统 SHALL 支持现象成功判定：优先自动（串口温湿度）；否则一键确认「我看到了/听到了」 | 两种路径都能标记主线硬件成功 |

### 5.4 课后测验

| ID | 需求 | 验收 |
|---|---|---|
| F-QZ-01 | 课后测验 SHALL 仅在主线成功后解锁 | 主线未完成入口禁用 |
| F-QZ-02 | 默认题型：3 道选择题 + 1 道操作复核（如确认串口读数或蜂鸣） | 题型符合默认 |
| F-QZ-03 | 通过标准：选择题至少 2 题正确 **且** 操作复核通过 | 边界用例：2 对+操作过=通过；1 对=不通过 |
| F-QZ-04 | 过程步骤中 SHALL NOT 插入任何测验或强制提问 | 与 F-AGT-02 联测 |

### 5.5 视觉与壳

| ID | 需求 | 验收 |
|---|---|---|
| F-VIS-01 | 色板 SHALL 使用 `#74B0E1` / `#F4C65C` / `#C0E2F9` 亮色儿童气质 | 设计走查 |
| F-VIS-02 | 工作台顶栏顺序 SHALL 为板型→连接→编译→烧录；底栏串口；Agent 右下；赛博猫 Rive | 布局走查 |
| F-VIS-03 | 目录视觉 SHALL 按同一气质重设计；SHALL NOT 照搬参考截图皮肤 | 设计对照 |

### 5.6 管理（P1）

| ID | 需求 | 优先级 |
|---|---|---|
| F-ADM-01 | 课程管理员可维护卡片字段、课包硬件型号、引导脚本、测验题 | P1 |

## 6. 用户故事（P0）

### Epic A — 目录选课

- **US-A1** 作为学习者，我想在目录用卡片看懂课做什么，以便决定学哪门。  
  **验收：** F-CAT-01/02/04。
- **US-A2** 作为学习者，我想点「开始课程」进入工作台，且在目录不被 Agent 打断。  
  **验收：** F-CAT-03、F-AGT-01。

### Epic B — 课内引导

- **US-B1** 作为学习者，进入第一课后我想一步步被告知做什么和为什么，中间不用答题。  
  **验收：** F-AGT-02/04、F-QZ-04。
- **US-B2** 作为学习者，离开再进入同一课时期望能接着学（尽力）。  
  **验收：** F-AGT-03（P1 强保证）。

### Epic C — 连线与真源

- **US-C1** 作为学习者，我想按「连线图」接好 DHT22 和蜂鸣器。  
  **验收：** F-WIR-01/03。
- **US-C2** 作为平台，连线合法性以 board.json 为准且行为对标 aily、不抄壳。  
  **验收：** F-WIR-02/04。

### Epic D — 工具链闭环

- **US-D1** 作为学习者，我想在顶栏完成连接、编译、烧录，并在底栏看串口。  
  **验收：** F-DEV-01、F-BLD-01、F-FLS-01、F-SER-01、F-BRD-01。
- **US-D2** 作为学习者，我想系统或我自己能确认「课成功了」。  
  **验收：** F-HW-01。

### Epic E — 课后测验

- **US-E1** 作为学习者，做完主线后我想用简短测验巩固，而不是学的时候被考。  
  **验收：** F-QZ-01/02/03。

### 旧故事处置

| 旧 ID | 处置 |
|---|---|
| ST-303 首课硬件核验 | **Superseded** → 由 US-C1 + US-D2 + 课包 DHT22/蜂鸣器 替换 |
| ST-403 接线查看器 | **Superseded** → 由 US-C1/C2（连线图查看器）替换 |

新故事实现时使用新 ID；旧 ID 仅作追溯。

## 7. Agent 引导状态机（产品）

```text
[目录/未选课]  Agent=IDLE（禁止逐步引导）
      │ 开始课程
      ▼
[工作台就绪]   Agent=GUIDING（逐步 + WHY）
      │ 主线硬件成功
      ▼
[主线完成]     Agent=WRAP_UP（导向测验）
      │ 打开测验
      ▼
[测验中]       Agent=QUIET_HELP（可答疑，不挡）
      │ 返回目录
      ▼
[目录]         Agent=IDLE（课内进度保存）
```

非法迁移：IDLE → 直接出 quiz；GUIDING → 插入 quiz 门闩。

## 8. 连线图（产品层）

| 层级 | 名称 | 谁看见 |
|---|---|---|
| 对外 | 连线图（Wiring Diagram） | 学习者、课程文案、UI |
| 对内 | ConnectionGraph（+ 实现所需 AWS/pinmap 等） | 工程 |
| 真源 | `board.json` 引脚能力 | 工程；校验以它为准 |

**对标策略：** 行为与约定对标 aily；**禁止**复制 GPL 壳。细节 R5。

## 9. 第一课课包（默认）

| 传感器 | DHT22 |

## 10. 视觉与文案约束

- 色板与工作台壳：冻结（F-VIS-01/02）。
- 目录：同气质重设计（F-VIS-03）。
- 禁用对外词：Wiring Graph（作为产品名/SoT）。
- 推荐对外词：连线图、课程、开始课程、编译、烧录、串口、课后测验。

## 11. 指标（试点）

| 指标 | 定义 |
|---|---|
| M1 | 目录 → 进入第一课转化率 |
| M2 | 第一课主线完成率（硬件成功） |
| M3 | 主线完成 → 开始测验转化率 |
| M4 | 测验通过率（按 F-QZ-03） |
| M5 | 连线/编译/烧录步骤中位耗时与求助率 |
| M6 | 连线错误导致失败占比 |
| M7 | 目录被 Agent 打断投诉 ≈ 0 |

指标 **不得** 依赖引导淡出进度。
