## 1. 一句话

MakeFast 是面向儿童与青少年的亮色可视化嵌入式学习工作台：学习者先在**课程目录**选课，进入课程工作台后才由 Agent 逐步引导并讲清 WHY，在 **XIAO ESP32-S3** 上完成「感知（温湿度）→ 反馈（蜂鸣器）」第一课，主线成功后再测验。

---

## 2. 为什么做（问题）

- 传统嵌入式入门同时要懂接线、板型、编译烧录与代码，儿童容易在中途卡住且不知道「为什么要这一步」。
- 仅提供图形化积木、缺少**持续讲解 WHY** 的引导，无法建立可迁移的硬件直觉。
- 若一进产品就被 Agent 抢引导，学习者无法先浏览「这门课做什么」再决定开始，目录决策被打断。
- 连线若使用自造术语或错误真源，会与常见工具链（如 aily 约定）脱节，增加课程制作与排错成本。

---

## 3. 为谁做（角色）

| 角色 | 目标 |
|---|---|
| 访客 | 在目录页快速理解有哪些课、难度与板型，决定是否进入第一课 |
| 学习者 | 选课后在持续引导下完成第一课硬件闭环，理解每步 WHY，课后巩固 |
| 课程管理员 | 配置/发布以板型与连线图为基础的课程内容与目录元数据 |
| 平台管理员 | 保障环境、权限与试点指标可控 |

本 Brief 的体验主路径以 **学习者** 为中心；管理员能力在 PRD 展开。

---

## 4. 产品原则（NEW 锁定）

1. **第一课固定硬件**：Seeed XIAO ESP32-S3 + 温湿度传感器 + 蜂鸣器（具体型号以课程包为准，见待补输入）。
2. **引导节奏**：主线完成前持续逐步引导；每一步说明做什么与 **WHY**；**过程中不提问、不穿插 quiz**。
3. **测验时机**：仅在主线步骤与硬件成功（可编译、可烧录、串口/现象可验证）之后进行课后测验。
4. **Agent 启动时机（R1.1）**：
   - Agent **以课程为单元**：用户**进入某一课程**后，才开始该课的逐步引导。
   - **目录 / 总览页不抢引导**：可展示课程信息与入口，但不得自动开讲、不得打断浏览与选课。
   - 退出课程回到目录后，课程内引导暂停；再次进入同一课程可从进度续导（细节 PRD 定）。
5. **课程目录优先（R1.1）**：产品主入口含**课程总览/目录**；卡片须说清「这门课做什么」，再进入工作台。
6. **连线语义**：
   - 对外名称：**连线图**（Wiring Diagram）
   - 对内模型：ConnectionGraph（及 AWS、pinmap 等实现要素）
   - 引脚能力真源：**board.json**
   - 不对用户或对外文档使用「Wiring Graph」作为产品名或 SoT
   - 行为与约定对标 aily；**遵守 GPL：复用约定与行为，不硬抄壳**
7. **视觉与工作台冻结**：
   - 亮色儿童向：`#74B0E1` / `#F4C65C` / `#C0E2F9`
   - 顶栏主路径：`板型 → 连接 → 编译 → 烧录`（进入课程工作台后）
   - 底栏：串口
   - Agent：右下；赛博猫：Rive
   - 目录页视觉须符合上述气质**重设计**；可参考既有信息结构，不得照搬参考截图的视觉风格
8. **旧 BMAD 冲突项作废**：引导淡出主路径、过程 quiz、Wiring Graph SoT、旧 PED、未按新硬件的 ST-303、未按新连线模型的 ST-403 等，详见 R0；不得在 Brief/PRD 中复活。

## 5. 学习者主线（入口 → 第一课闭环）

### 5.0 主线入口（R1.1）

```text
打开 MakeFast
  → 课程总览 / 目录（浏览卡片，无 Agent 抢引导）
  → 选择一门课程（如第一课）
  → 进入该课工作台
  → Agent 开始本课逐步引导 + WHY
  → …（见 5.1）
```

### 5.1 课内闭环（进入课程之后）

```text
工作台内
  → 选择/确认板型 XIAO ESP32-S3
  → 按连线图完成温湿度 + 蜂鸣器连接（持续引导 + WHY）
  → 连接设备
  → 编译
  → 烧录
  → 串口/现象确认（读温湿度、蜂鸣器反馈）
  → 主线完成
  → 课后测验
```

### 5.2 课程目录信息结构（In Scope）

目录以**课程卡片**展示「做什么」；信息结构可参考常见入门教程目录，**视觉按亮色儿童气质重设计**。卡片建议字段：

| 字段 | 说明 |
|---|---|
| 封面图 | 表达本课成果/场景，儿童可读 |
| 标题 | 课程名（如第一课主题） |
| 星级难度 | 直观难度 |
| 入门标签 | 如「入门」 |
| 板型/生态标签 | 如 ESP32、Arduino 等（第一课突出 ESP32 / XIAO） |
| 分类 | 如「入门教程」 |

目录页允许筛选/分类浏览；**不允许**在未进入课程时由 Agent 开讲或强制引导蒙层。

### 5.3 引导要求（仅课内）

- 每步：目标一句话 + WHY（为何现在做、不做会怎样）+ 成功长什么样。
- 过程中：**零提问、零 quiz、零「先答对再往下」门闩**。
- 允许：提示、高亮、演示、防错纠错、重试；不允许把测验塞进步骤间。
- 目录页：静默；最多提供非打断的轻提示（如「点卡片开始」），不进入逐步引导态。

### 5.4 成功定义（产品级）

学习者从目录选入第一课，在引导下走完顶栏主路径，观察到与温湿度/蜂鸣器相关的可验证现象，并完成课后测验。具体通过分数与题型在 PRD 定义（待补输入）。

## 6. 范围

### 6.1 In Scope（本阶段）

- **课程总览 / 目录界面**（卡片信息结构见 5.2；亮色儿童视觉重设计）
- 选课进入工作台后的第一课课程体验（引导 + 连线图 + 编译烧录 + 串口）
- **Agent 按课程启动**（进课才引导；目录不抢引导）
- 连线图查看与教学语义（对标 aily 行为，board.json 真源）
- 亮色儿童工作台壳（按冻结视觉）
- 课后测验（主线后）
- 与上述冲突的旧文档/故事重梳（R0–R9）

### 6.2 Out of Scope（本阶段明确不做）

- 目录页自动开讲 / 未选课即进入逐步引导
- 以 assisted→autonomous 淡出为主的进度体系
- 过程中强制提问/quiz 门闩
- 对外推广「Wiring Graph」品牌/SoT
- 硬抄 aily GPL 壳或资源
- 重开已定色板与工作台顶栏信息架构争论（目录页是新表面，须服从同一气质，不另起色板）
- 照搬参考截图的视觉皮肤
- 非第一课硬件套件的并行首发（可规划，但不挡第一课）

## 7. 差异化

| 维度 | MakeFast |
|---|---|
| 入口 | 先看清课是什么，再进课学；Agent 不抢目录 |
| 教学 | 课内持续 WHY 引导，先做会再测 |
| 硬件课 | 第一课即完整「感知 + 输出」闭环 |
| 连线 | 对标常见工具链约定，真源清晰，儿童可读的「连线图」 |
| 工作台 | 顶栏编译→烧录路径显性，底栏串口，亮色儿童 UI |

## 8. 指标方向（试点，细节进 rewards 文档）

指标不得依赖「引导淡出进度」。建议方向：

- 目录→进入第一课的转化率
- 第一课主线完成率（到烧录并出现可验证现象）
- 主线完成到开始课后测验的转化率
- 课后测验通过率
- 在连线/编译/烧录步骤的中位耗时与求助率
- 因连线错误导致的失败占比（用于改进连线图与引导文案）
- 目录页被 Agent 打断相关的负面反馈（目标：趋近于 0）
