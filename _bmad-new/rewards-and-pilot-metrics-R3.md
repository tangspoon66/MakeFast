---

## 1. 原则

1. **奖励完成与理解**，不奖励「少用 Agent / 变自主」。  
2. **指标不得依赖引导淡出**（OBS-01 已作废）。  
3. 过程零 quiz ⇒ **过程中无答题得分**；唯一知识检测在课后测验。  
4. 试点先证明快乐路径，再谈长期留存花活。

---

## 2. 假设（Assumptions）

| ID | 假设 |
|---|---|
| AR-01 | 试点周期默认 2 周；样本以完成「打开 App」的学习者计 |
| AR-02 | 第一课为唯一必测课包（DHT22 + 有源蜂鸣器） |
| AR-03 | 「求助」= 主动点 Agent 帮助 / 重试引导步骤（不含系统自动提示） |
| AR-04 | 北星偏激活：第一课主线硬件成功（M2） |
| AR-05 | 奖励以课内即时反馈为主；积分体系若未建则只用徽章/庆祝（P0 不做复杂商城） |

---

## 3. 奖励设计（P0）

| 触发 | 奖励 | 说明 |
|---|---|---|
| 首次进入第一课工作台 | 轻提示「开始冒险」 | 非积分 |
| 连线步骤完成（课包定义） | 步骤勾选 + 短鼓励 | 无分值门闩 |
| 编译成功 | 短庆祝 | — |
| 烧录成功 | 短庆祝 | — |
| 现象成功（自动或确认） | **主线完成徽章**「第一课做成了」 | 解锁测验 |
| 课后测验通过 | **理解徽章** + 回目录 CTA | 按 F-QZ-03 |
| 测验未通过 | 鼓励重试 + 简短解析 | 不惩罚回目录 |

**明确不做（本阶段）：**

- 因「少问 Agent」加分；
- 因「更快淡出协助」升级；
- 过程答题连击；
- 挫败惩罚（扣星、降级）。

---

## 4. 试点指标（对齐 PRD M1–M7）

| ID | 名称 | 定义 | 目标（试点建议） | 采集 |
|---|---|---|---|---|
| M1 | 选课转化 | 目录曝光第一课 → 点击开始课程 | ≥ 40% | 前端事件 |
| M2 | 主线完成率 | 开始课程 → 现象成功 | ≥ 50%（首周可放宽观察） | 进度事件 |
| M3 | 测前转化 | 现象成功 → 打开测验 | ≥ 70% | 事件 |
| M4 | 测验通过率 | 提交测验 → 通过（F-QZ-03） | ≥ 60% | 判分 |
| M5a | 步骤耗时 | 连线/连接/编译/烧录各中位时长 | 建基线，异常飙高再优化 | 计时 |
| M5b | 求助率 | 上述步骤中触发求助的会话占比 | 观察；高求助+高完成可接受 | 事件 |
| M6 | 连线失败占比 | 主线失败主因归类为连线的比例 | 下降趋势 | 失败归因 |
| M7 | 目录打断 | 目录态 Agent 强制引导相关投诉/会话标记 | **= 0** | 质检+开关配置审计 |

### 禁止作为北星或阶段性 KPI

- 自主度 / 淡出等级；
- 过程 quiz 正确率；
- 「无 Agent 完成率」。

---

## 5. 漏斗与护栏

```text
打开 App → 目录曝光 → 开始第一课 → 接线完成 → 连接成功
  → 编译成功 → 烧录成功 → 现象成功 → 开测验 → 测验通过
```

**护栏：**

- M7 必须接近 0；若配置错误导致目录开讲，判发布阻塞。  
- M2 过低时优先查：连线文案、board 校验误报、编译错误可读性——**不是**加过程 quiz。  
- M4 过低时改题或课后解析，**不是**把题搬回过程。

## 6. 报告节奏（试点）

| 节奏 | 内容 |
|---|---|
| 每日 | M1/M2 粗看；M7 异常告警 |
| 每周 | 全漏斗 + M5 分步 + 失败归因 Top3 |
| 试点结束 | 是否达成 M-P0 体验；奖励是否只需徽章或要加轻量积分（决策，不默认做） |
