## 1. 设计原则（不可违背）

1. **色板冻结：** `#74B0E1`（主蓝）/ `#F4C65C`（强调黄）/ `#C0E2F9`（浅底）。亮色儿童向。  
2. **工作台壳冻结：** 顶栏 `板型 → 连接 → 编译 → 烧录`；底栏串口；Agent **右下**；赛博猫 Rive。  
3. **目录卡片六要素：** 封面、标题、星级难度、入门标签、板型/生态标签（ESP32/Arduino…）、分类。  
4. **文案：** 对外「连线图」；禁止对外「Wiring Graph」。  
5. **Agent：** 仅课内 GUIDING；目录 IDLE，无强制蒙层/自动开讲。  
6. **参考截图：** 只借信息结构，**禁止**照搬皮肤。

## 2. 假设（Assumptions）

| ID | 假设 |
|---|---|
| AU-01 | 桌面优先（≥1280 宽）；平板可缩放，手机非 P0 |
| AU-02 | 中文 UI 为首发语言 |
| AU-03 | 赛博猫资源已有 Rive；目录态用 Idle，课内用引导表情切换 |
| AU-04 | 第一课卡片数据可由 mock 驱动演示 |

## 3. 信息架构（屏幕）

```text
S0 App Shell
S1 课程目录（主入口）
S1a 课程详情（可选薄层/侧抽屉）
S2 课程工作台
S2a 连线图面板（工作台内）
S2b 串口面板（底栏）
S3 课后测验（模态或全屏子页）
```

## 4. 文字线框

### 4.1 S1 课程目录

```text
┌─────────────────────────────────────────────────────────────┐
│ MakeFast                                    [头像/设置 P1]   │
├─────────────────────────────────────────────────────────────┤
│ 入门教程(选中) | 全部 | …筛选芯片                            │
│                                                             │
│ ┌──────────┐  ┌──────────┐  ┌──────────┐                    │
│ │ 封面图    │  │ 封面     │  │ …        │                    │
│ │ [开始这里]│  │          │  │          │                    │
│ │ 标题      │  │ 标题     │  │          │                    │
│ │ ★★☆ 入门  │  │ ★…      │  │          │                    │
│ │ ESP32     │  │          │  │          │                    │
│ │ 入门教程  │  │          │  │          │                    │
│ │ [开始课程]│  │ [开始]   │  │          │                    │
│ └──────────┘  └──────────┘  └──────────┘                    │
│                                                             │
│                              (右下赛博猫 Idle，无对话框抢麦)   │
└─────────────────────────────────────────────────────────────┘
```

**交互：** 点卡片或「开始课程」→ S2。可选点封面非 CTA 区 → S1a 详情（仍无 Agent 引导）。

### 4.2 S1a 课程详情（可选）

```text
┌──────────────────────────────┐
│ ← 返回目录                    │
│ [大封面]                      │
│ 标题 / ★ / 标签们             │
│ 这门课做什么（2–4 句）         │
│ 需要：XIAO ESP32-S3 · DHT22 · 有源蜂鸣器 │
│        [ 开始课程 ]           │
└──────────────────────────────┘
```

### 4.3 S2 课程工作台

```text
┌─────────────────────────────────────────────────────────────┐
│ ← 目录   第一课标题                                          │
│ [板型] → [连接] → [编译] → [烧录]     ← 当前步高亮+进度点    │
├────────────────────────────┬────────────────────────────────┤
│ 主区：积木/代码编辑         │ 连线图面板                      │
│                            │ 「连线图」标题                   │
│                            │ [XIAO]—[DHT22]                 │
│                            │      └—[蜂鸣器]                 │
│                            │ 图例/引脚提示（儿童句）           │
├────────────────────────────┴────────────────────────────────┤
│ 串口 ▾  最新一行输出…                              [清空][…] │
├─────────────────────────────────────────────────────────────┤
│                                      ┌──Agent 气泡────────┐ │
│                                      │ 现在做 / 为什么 /   │ │
│                                      │ 成功时…    [下一步] │ │
│                                      └────(猫 Rive)───────┘ │
└─────────────────────────────────────────────────────────────┘
```

**顶栏步进：** 可回看已完成步；未满足前置时点击给出引导提示（非 quiz）。

### 4.4 S3 课后测验

```text
┌─────────────────────────────────────┐
│ 课后小练习（巩固）            [关闭] │
│ Q1 ( ) …  Q2  Q3                   │
│ 操作复核：□ 我在串口看到温湿度 / 听到蜂鸣 │
│              [提交]                 │
│ 结果：通过 → 徽章 + [回目录]         │
│      未过 → 解析 + [再试]           │
└─────────────────────────────────────┘
```

仅主线成功后可从工作台入口打开。

## 5. 组件清单

### 5.1 基础

| 组件 ID | 名称 | 说明 |
|---|---|---|
| C-COLOR | ColorTokens | Primary `#74B0E1` Accent `#F4C65C` Surface `#C0E2F9` + 文本/成功/警告/错误语义色 |
| C-TYPE | Typography | 标题/正文/辅助；儿童友好偏大字号 |
| C-BTN | Button | Primary / Secondary / Ghost / Danger |
| C-CHIP | Chip/Tag | 入门、ESP32、Arduino、分类 |
| C-STAR | StarRating | 只读星级 |
| C-BADGE | Badge | 「开始这里」、主线完成、理解徽章 |

### 5.2 目录

| 组件 ID | 名称 | 说明 |
|---|---|---|
| C-CAT-FILTER | CatalogFilter | 默认选中「入门教程」 |
| C-CAT-CARD | CourseCard | 六要素 + CTA「开始课程」 |
| C-CAT-GRID | CourseGrid | 响应式卡片栅格 |
| C-CAT-EMPTY | CatalogEmpty | 空态 + 非打断提示文案 |

### 5.3 工作台壳

| 组件 ID | 名称 | 说明 |
|---|---|---|
| C-TOP-STEPPER | ToolchainStepper | 板型→连接→编译→烧录；状态：todo/current/done/error |
| C-EDITOR | BlockCodePane | 积木/代码主区（实现对界） |
| C-WIRING | WiringDiagramPanel | 标题固定「连线图」；渲染课包图 |
| C-SERIAL | SerialDock | 底栏；可折叠；最新行预览 |
| C-STATUS | StatusLight | 连接/编译/烧录交通灯+短词 |

### 5.4 Agent

| 组件 ID | 名称 | 说明 |
|---|---|---|
| C-AGENT-DOCK | AgentDock | 右下容器；目录可显猫但 **无引导气泡强制** |
| C-AGENT-STEP | GuideStepCard | 现在做 / 为什么 / 成功时 + 下一步 |
| C-CAT-RIVE | CyberCatRive | Idle vs Guiding 状态机绑定 |

### 5.5 测验与奖励

| 组件 ID | 名称 | 说明 |
|---|---|---|
| C-QUIZ | QuizModal | 3 选择 + 1 操作复核 |
| C-CELEBRATE | CelebrateToast | 短庆祝/徽章弹出 |

### 5.6 文案键（禁止项）

| 键 | 正确 | 禁止 |
|---|---|---|
| wiring.title | 连线图 | Wiring Graph |
| cta.start | 开始课程 | 开始挑战测验（目录） |
| quiz.title | 课后小练习 | 考试 |

## 6. Agent 可见性规则

| 表面 | 猫 | 引导气泡 |
|---|---|---|
| S1 目录 | Idle 可显示 | **关闭**（最多非打断 1 句 Tip，可关） |
| S1a 详情 | Idle | **关闭** |
| S2 工作台 | Guiding | **开启** GuideStepCard |
| S3 测验 | Quiet | 可选轻答疑，不挡提交 |

---

## 7. 无障碍与反馈

- 步进状态不只靠颜色（配短词/图标）。  
- 焦点环可见；主 CTA 面积足够点击。  
- 错误：短句 + 建议，堆栈进「详情」。  
- 蜂鸣成功：串口/视觉确认通道并存（Experience AX）。
