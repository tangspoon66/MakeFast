# 用户手册 - 固件管理系统

## 用户端

### 浏览固件库

访问 `/firmware` 页面查看所有已发布的固件包。

每个固件卡片显示：
- 项目名称和版本
- 项目描述（截断至 200 字符）
- 支持的开发板
- 标签分类
- 缩略图

### 筛选和搜索

- **开发板筛选**: 使用下拉框选择目标开发板，只显示兼容的固件
- **标签筛选**: 点击标签过滤相关固件（多标签为 OR 逻辑）
- **关键词搜索**: 输入关键词实时搜索项目名称和描述

### 查看固件详情

点击固件卡片进入详情页面，查看：
- 完整项目描述
- 支持的开发板列表
- 各文件大小和总大小
- 版本信息和创建时间
- 兼容性状态

### 烧录固件到设备

1. 使用 USB 线连接 ESP32 开发板
2. 在固件详情页面点击 **"烧录到设备"**
3. 如果未选择串口，系统会提示选择
4. 如果检测到开发板不兼容，会显示警告（可选择继续）
5. 等待烧录完成，查看进度条
6. 烧录成功后会显示成功通知

**注意事项**:
- 需要使用 Chrome 89+ 或 Edge 89+ 浏览器（支持 Web Serial API）
- 烧录过程中不要断开 USB 连接
- 如果烧录失败，尝试按住开发板 BOOT 按钮后重试

### 下载固件包

在固件详情页面点击 **"下载固件包"**，系统会打包所有固件文件为 ZIP 下载。

下载的 ZIP 包含：
- `bootloader.bin` - 引导加载程序
- `partitions.bin` - 分区表
- `boot_app0.bin` - Boot 应用
- `app.bin` - 主应用程序
- `metadata.json` - 项目元数据

## 管理员端

### 登录管理后台

1. 访问 `/admin/login`
2. 输入管理员用户名和密码
3. 登录成功后自动跳转到仪表板

**安全机制**:
- 连续 5 次登录失败后账户锁定 30 分钟
- Token 有效期 24 小时，过期需重新登录

### 仪表板

管理员首页 (`/admin`) 显示系统概览：
- 固件包总数
- 存储空间使用量
- 近 30 天下载次数
- 近 30 天烧录次数
- 热门固件 Top 10
- 存储空间警告（超过 80% 时显示）

### 上传固件包

1. 进入 `/admin/firmware/upload`
2. 上传 ZIP 文件（拖拽或点击选择）
   - ZIP 必须包含: `bootloader.bin`, `partitions.bin`, `boot_app0.bin`, `app.bin`
   - 单个文件不超过 10MB
3. 填写元数据：
   - **项目名称** (3-100 字符)
   - **描述** (10-2000 字符)
   - **版本** (语义化版本，如 `1.0.0`)
   - **支持的开发板** (至少选择一个)
   - **标签** (可选，最多 5 个，每个 2-20 字符)
   - **发布状态** (已发布/草稿)
4. 上传缩略图（可选）
   - 支持 PNG、JPEG、WebP 格式
   - 文件大小不超过 500KB
   - 尺寸 200x200 ~ 1000x1000 像素
5. 点击提交

### 管理固件列表

在 `/admin/firmware` 页面可以：
- 查看所有固件（包括未发布的草稿）
- **编辑**: 修改项目名称、描述、版本、标签等
- **删除**: 删除固件包（需确认）
- **发布/取消发布**: 切换固件的可见状态
- **排序**: 按下载次数或烧录次数排序

### 版本管理

- 同一项目可以上传多个版本
- 版本号必须遵循语义化版本格式 (`major.minor.patch`)
- 新版本号必须大于已有版本
- 最高版本自动标记为 "Latest"
- 用户默认看到最新版本

### 导入导出

- **导出**: 点击固件的导出按钮，下载包含固件文件和元数据的 ZIP
- **导入**: 点击导入按钮，上传之前导出的 ZIP 包
  - 如果项目名称和版本已存在，会提示是否覆盖

### 配置 AI 助手

在 `/admin/ai-config` 页面配置 AI 代码助手：

1. **API Key** - AI 服务的密钥
2. **API Base URL** - API 地址（必须是 HTTPS）
3. **Model** - 模型名称
4. **Temperature** - 生成温度 (0.0-2.0)
5. **Max Tokens** - 最大生成长度 (100-8000)

配置流程：
1. 填写配置信息
2. 点击 **"测试连接"** 验证配置是否正确
3. 测试通过后点击 **"保存"**

### 常见问题

**Q: 忘记管理员密码怎么办？**
A: 重新运行 `backend/scripts/init_admin.py` 生成新的密码哈希，更新 `.env` 文件后重启服务。

**Q: 固件上传失败提示存储空间不足？**
A: 清理不需要的固件包，或扩展存储空间。系统要求至少 1GB 可用空间。

**Q: 如何批量管理固件？**
A: 使用导入导出功能在不同环境间迁移固件包。

**Q: 用户看不到我上传的固件？**
A: 检查固件的发布状态，确保已设置为"已发布"。草稿状态的固件只有管理员可见。
