# MakeFast MVP 试点发布与回滚手册

这份手册对应 BMAD `ST-702`。它只描述个人版 MVP；学校教师后台、短信登录和家长端不在本次发布范围。

## 发布前门禁

1. `backend/venv/bin/python -m pytest -q backend/tests` 通过。
2. `cd frontend && npm test -- --run` 通过，随后 `npm run build` 通过。
3. 管理端课程草稿通过 schema 校验，并且发布的是不可变版本。
4. 首课的板卡、DHT11、蜂鸣器和成品素材均有准确型号、来源/许可、替代文字和核验状态；没有这些证据时，课程必须保持 `pending`，不得开放真实接线指导。
5. 用测试账号走一遍：游客预览 -> 注册 -> 总览 -> 创建项目 -> 材料确认 -> Agent 对话 -> 代码保存 -> 模拟编译/串口 -> 奖励总览。
6. 不把完整源代码、串口原始输出或 Agent 对话写入默认遥测；反馈日志必须由用户主动勾选。

## 数据备份与迁移

1. 停止写入窗口或启用维护提示。
2. 复制学习 SQLite 数据库到带日期的备份目录，并记录校验和：

   ```bash
   cp backend/data/learner.sqlite3 backend/data/backups/learner-$(date +%Y%m%d-%H%M%S).sqlite3
   shasum -a 256 backend/data/backups/learner-*.sqlite3 | tail -1
   ```

3. 只运行向前兼容的 `CREATE TABLE IF NOT EXISTS` / `ALTER TABLE ADD COLUMN` 迁移；不要删除旧列或重写已发布课程版本。
4. 记录备份文件、迁移版本、操作人和开始/结束时间。

## 功能开关与降级

- `learning_course_preview`: 关闭后，游客仍可看到落地页，但不再进入课程预览。
- `learning_workbench`: 关闭后，已登录用户回到旧编辑器入口；项目数据不删除。
- `learning_agent`: 关闭后，隐藏 Agent 角色和提案按钮，保留课程步骤、代码、积木和串口调试；已保存对话只读保留。
- `learning_rewards`: 关闭后停止发放新积分，但不删除既有流水和徽章。
- `course_temperature_alert_version`: 切回上一个已发布课程版本；不要修改旧版本内容。

## 回滚步骤

1. 先关闭 `learning_agent` 或 `learning_workbench`，确认旧编辑器可打开。
2. 如果问题只在课程内容，管理端选择上一版已发布版本，验证版本号和素材核验状态后再切换。
3. 如果问题来自 schema/API 迁移，停止服务，保留故障数据库副本，用最近一次通过校验的备份恢复，再启动后端并执行只读健康检查。
4. 检查：登录、项目列表、项目保存冲突保护、旧编辑器编译入口和管理员登录。
5. 发布回滚说明，包含影响时间、受影响版本、恢复的备份校验和下一步修复负责人。

## 恢复验证

- 账号仍能登录，游客不能调用 Agent、工作台、源代码或固件下载。
- 项目 `revision` 没有倒退；冲突保存不会覆盖较新版本。
- 课程旧版本仍可读取，已绑定项目不被悄悄改绑。
- Agent 关闭时没有固定 AI 对话栏，串口和日志仍可使用。
- 奖励流水保留历史规则和原始事件；重复请求不会重复发分。

## 支持诊断

只收集用户明确同意的页面地址、浏览器兼容性、错误类型和最近有限日志。默认不收集家庭信息、精确年龄、完整代码、完整串口原始输出或完整 Agent 对话。儿童用户遇到硬件问题时，优先让家长协助检查电源和接线，平台不要求上传家庭信息。
