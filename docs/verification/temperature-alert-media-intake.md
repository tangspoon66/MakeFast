# 首课素材接收清单

这份清单对应 `temperature-alert` 首课的 `CourseMedia` 和 `CourseComponent` 字段。可以提供实拍，也可以提供与实际购买型号逐项核对过的技术渲染图。相似但型号不确定的生成图不能进入公开课程。

## 需要的四类素材

| 素材 | 必须说明 | 还要核对 |
| --- | --- | --- |
| XIAO ESP32-S3 Sense 开发板 | 准确型号、来源/许可、中文替代文字 | 外露 GPIO 与课程使用范围；Sense 摄像头扩展是否与图一致 |
| 三针 DHT11 温湿度模块 | 准确商品或模块型号、来源/许可、中文替代文字 | VCC、DATA、GND 丝印顺序和图片上的物理位置 |
| 三针 3.3V 有源高电平蜂鸣器模块 | 准确商品或模块型号、来源/许可、中文替代文字 | VCC、GND、SIG 顺序，3.3V 电气行为和高电平触发行为 |
| 温湿度提醒器成品 | 来源/许可、中文替代文字 | 成品确实使用以上固定套件，不混入未声明元件 |

## 渲染图要求

- 文件格式可用 PNG、JPEG 或 WebP；透明背景只适用于单个器件，不要把多个状态或多个型号拼在一张图里。
- `exact_variant` 必须写到可购买/可复核的型号；只有“DHT11 模块”“蜂鸣器模块”这种泛称不能发布。
- `technical_render` 必须填写 `variant_check`，说明渲染图如何与实物照片、商品页或官方尺寸/引脚图比对。
- 每张图都要有 `source`、`license` 和 `alt`；无法确认使用权时保持 `pending`，不放入已发布版本。

## 核验顺序

1. 先固定 DHT11 和蜂鸣器的具体型号。
2. 对照型号核对 VCC/DATA/GND 或 VCC/GND/SIG 顺序和图片坐标。
3. 在实际 XIAO ESP32-S3 Sense 上确定只使用外露且未被 Sense 功能占用的 GPIO。
4. 记录每根线的连续性、电源电压、编译、烧录、串口输出和蜂鸣器启动短响结果。
5. 将照片/渲染图、pinmap、接线记录和实测证据写入同一课程版本，再运行发布校验。

在第 4 步完成前，课程可以继续做界面和内容预览，但不能向学生显示具体 GPIO 接线指导，也不能把“我已准备好”复选框解释成平台检测到了实物。
